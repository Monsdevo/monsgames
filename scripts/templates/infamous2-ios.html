A PlayStation 3 game, finding its way onto a device it was never built for.

This project adapts inFAMOUS 2 into a standalone native iOS application. It builds on existing PS3 static-recompilation and macOS work, bringing the runtime, graphics, input and local game data to iPhone.

The game runs on the phone itself. This is not emulation, cloud gaming or Remote Play. A Mac is used for development and installation; gameplay runs independently on the device.

Original architecturePS3 code

Game logic, built for a very different machine.

Static recompilationNative ARM64

CPU code translated ahead of time. No CPU JIT required.

On-device executioniPhone + Metal

Native iOS runtime, rendering and selected compute workloads.

Progress measured in frame time.

Rendering a PS3 game on iPhone means more than getting pixels on screen. CPU work, GPU submission and synchronization all compete for the same frame.

Lighting & SSAO

The Metal paths are integrated and tested on the phone. Separate short comparisons found roughly 25% higher FPS for Metal lighting versus its SPU reference, and 27% for Metal SSAO with Metal lighting already enabled. These results are not additive or full-game guarantees.

The serial renderer

Current work targets redundant RSX state processing, vertex preparation and copying, texture-change detection and CPU/GPU scheduling. The latest RSX change still needs an on-device comparison.

Faster locally is not always faster in-game.

ARM64 and Metal experiments for geometry, skinning and culling have not demonstrated a repeatable gameplay FPS gain. Small GPU jobs can cost more to submit and synchronize than they save.
